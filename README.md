# Sistema de Gestión de Ventas y Stock de Vehículos 🚗

Proyecto académico desarrollado en equipo en la UTN FRGP.  
Este sistema de escritorio en C++ está diseñado para gestionar las ventas y el stock de una empresa fabricante de vehículos con una red de concesionarios.

---

##  Descripción

El sistema permite administrar diferentes áreas de la empresa a través de un menú principal con submenús específicos para:  
- Gestión de vehículos  
- Gestión de ventas  
- Gestión de clientes  
- Gestión de sucursales  
- Gestión de vendedores  

---

##  Tecnologías y conceptos utilizados

- Lenguaje: C++  
- Programación orientada a objetos (POO)  
- Estructuras de datos  
- Validaciones de entrada y control de errores  
- Persistencia de datos mediante archivos   
- Trabajo colaborativo en equipo
